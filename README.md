# Trading Journal – GitHub

Eine eigenständige Trading-Journal-Webapp im Look des gezeigten Journals.

## Start
Einfach `index.html` öffnen.

## GitHub Pages
1. Repository auf GitHub erstellen.
2. Alle Dateien dieses Ordners hochladen.
3. **Settings → Pages → Deploy from branch → main / root**.
4. Die angezeigte GitHub-Pages-Adresse öffnen.

## Funktionen
- Dark Trading-Journal UI
- Trade-Tabelle mit Status, Long/Short, Symbol, Entry/Exit, P&L und Setup
- Add-Trade-Dialog
- lokale Speicherung per `localStorage`
- Performance-Karten und Charts
- Setup-/Mistake-Auswertung
- responsive Grundansicht

Die Oberfläche ist als eigene Implementierung nach dem bereitgestellten Video aufgebaut; sie benötigt keinen Server.
